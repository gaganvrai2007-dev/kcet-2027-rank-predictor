# KCET 2027 Rank Predictor

A simple, browser-based tool that estimates an engineering rank using KCET
Physics, Chemistry and Mathematics marks, along with PUC / Class 12 marks.

## Features

- Accepts KCET PCM marks (each subject out of 60).
- Accepts PUC / Class 12 PCM marks (each subject out of 100).
- Calculates KCET and PUC percentages.
- Combines the two percentages with equal weighting.
- Displays an estimated rank, an approximate range, and a broad result tier.
- Responsive layout with light and dark appearance support.

## Built With

- HTML
- CSS
- JavaScript

No frameworks, package installation, or build tools are required.

## Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`, or open it in any modern web browser.
4. Enter all six subject marks and select **Predict my rank**.

## How the Estimate Works

The predictor:

1. Adds the three KCET subject marks and converts the total to a percentage
   out of 180.
2. Adds the three PUC subject marks and converts the total to a percentage
   out of 300.
3. Gives both percentages equal weight to calculate a composite percentage.
4. Maps that composite percentage to an approximate rank using an
   interpolated reference curve in the JavaScript.

The rank range and result tiers are estimates generated by the project;
they are not official counselling predictions.

## Important Disclaimer

**This is an unofficial educational estimation tool, not an official KEA
rank predictor.** Its reference curve is approximate and is not presented
as verified historical or official KEA data. Actual KCET ranks and admission
outcomes can vary based on the exam's difficulty, candidate performance,
number of candidates, applicable rules, tie-break criteria, and counselling
updates.

Do not use this estimate as a guarantee of rank, college, branch, or seat
allotment. Check the latest announcements and results from the Karnataka
Examinations Authority (KEA) for authoritative information.

## Hosting with GitHub Pages

1. Push the contents of this folder to a GitHub repository.
2. Open the repository's **Settings**.
3. Select **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/(root)` folder, then save.
6. Once deployment finishes, GitHub will show the published site URL in
   the Pages section.
